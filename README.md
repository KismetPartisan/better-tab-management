# better-tab-management
Allows for better tab management using the keyboard in zen browser and firefox


### Features:
* Select tabs using ctrl+h and ctrl+i
* Close tabs using ctrl+y
* Discard tabs using ctrl+shift+y
  
### Planned features:
* Move tabs using ctrl+shift+h and ctrl+shift+i

### Potential features:
* Create/move tab groups
* Move tabs between zen workspaces
* Select multiple tabs at once (would need to find a way to give selected tabs a separate visual identity from the "hovered" tab, which might require chrome.css changes)
